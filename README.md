# kha2lil — Portfolio

Personal portfolio website built with **HTML**, **CSS**, and **JavaScript** — no frameworks, no build tools. Clean, performant, and fully responsive.

## Pages

- **Home** — Hero, about section, stats
- **Skills** — Tech stack with animated skill bars
- **Projects** — Dzire (e-learning platform) & MultiThreaded Text Analyzer
- **Services** — What I can build
- **Journey** — Learning timeline with filters
- **Blog** — Dev insights & case studies
- **Contact** — Social links & contact form

## Features

- Dark / light theme toggle
- Custom cursor with trail
- Scroll reveal animations
- Project modals with role-based views
- Journey timeline with category filters
- Mobile-first responsive design
- Formspree contact form integration

## Deployment

Deployed via **GitHub Pages** at [kha2alil.github.io/portfolio](https://kha2alil.github.io/portfolio/)
